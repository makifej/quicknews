Megjelent az Agibot, a Maces háttérben futó személyi AI-ügynök

Az Agibot egy Macen futó AI-asszisztens, amely a háttérben dolgozva kezeli a feladatokat, és üzenetküldőkön keresztül is elérhető.

0
Kipróbálom: Agibotagibot.sh

Az Ökte Çilmi által bemutatott Agibot egy mindig aktív személyi AI-ügynök, amely közvetlenül Mac számítógépeken fut. A szoftver az ablak bezárása után is működik a háttérben: képes reggeli összefoglalókat küldeni, webes feladatokat elvégezni, valamint értesíteni a felhasználót a fontos változásokról. A kommunikáció az applikáción kívül Telegramon és Slacken keresztül is folytatható.

Az eszköz teljesen ingyenes, ha a felhasználó a saját API-kulcsát használja, de akár ingyenes helyi modellekkel is futtatható. A rendszer támogatja a Claude, GPT, Gemini, Grok és DeepSeek modelleket is. A megjegyzett adatok és az emlékezet a felhasználó saját gépén tárolódnak, így a modellváltáskor sem vesznek el.

A biztonság érdekében az Agibot kötött szabályrendszert követ: a kockázatos műveleteknél (fájlírás, böngészővezérlés, törlés) előzetes jóváhagyást kér a felhasználótól Telegramon vagy Slacken. Ha nem érkezik válasz, a művelet nem fut le. A nem várt költségek elkerülésére napi költési limit is beállítható.

It’s a fixed policy, not the model’s judgment. Every tool has a setting you control: allow, ask or block. The app enforces it outside the model, so the model can’t decide something is “safe enough” and can’t approve itself. Out of the box, file writes, web fetches, scheduling, deleting memories and browser control are all set to ask. Shell access is off until you turn it on. Even then, every command asks, and you can’t set it to always allow. For messages, it can only reply in chats you’ve paired with it. It can’t message new people. On the “a fixed list will miss things” point: anything new, like the tools from an MCP server you just added, starts at ask. So when the list misses something, Agibot stops and asks you instead of going ahead. When it’s running unattended, approval requests come to you as buttons on Telegram or Slack. If you don’t answer, the answer is no. For your API key, you set a daily spending cap during setup. Agibot checks the estimated cost before every call, and if it doesn’t know a model’s price, it blocks the call rather than guess. Those are estimates, though, so I’d still set a limit with your provider too. So in the end, your trust goes into what you set to allow and which MCP servers you install.
